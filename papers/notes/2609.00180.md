# 2609.00180 — Asymmetries in Spontaneous and Instructed Deception
Josiah Luikham (independent). arXiv v1, 31 Aug 2026. 22 pp. incl. appendices.

## Research question
In Llama-3.1-70B-Instruct, how do *instructed* deception (system prompt says "be deceptive") and *spontaneous* deception (incentive in scenario, no instruction) relate? Tested via (i) direction geometry (cosine), (ii) cross-setting probe transfer, (iii) cross-setting activation steering; at binary (honest/deceptive) and type level (fabrication / omission).

## Definitions / typology
Follows Shi et al. 2026 ("From sycophancy to deception: a unified taxonomy for LLM spontaneous misalignment", arXiv 2604.04788):
- **Omission**: failing to provide relevant true info (withholding caveats, not disclosing uncertainty, concealing conflicting intentions).
- **Fabrication**: actively producing false content (nonexistent facts, fake citations, false promises).
- **Pragmatic distortion**: technically true but misleading via framing/emphasis/implicature (planned, dropped — too few spontaneous examples).
- Spontaneous = deception under incentive without instruction (the realistic deployment case). Instructed = explicit instruction.

## Methodology (implementable)
- **Data generation**: scenarios by GPT-5-mini (pipeline adapted from S. H. Wong notebook). Every system prompt = scenario + **ground-truth fact**; user asks question about the ground truth.
  - Instructed: system prompt includes a definitions block + "Answer questions honestly" / "...deceptively using fabrication" / "...using omission". Labels from instruction.
  - Spontaneous: system prompt adds an **incentive** (e.g., "If you report the guard failure and injury, OSHA will issue a stop-work order and heavy fines."). Split into fabrication- and omission-temptation lists. Labels from judge.
- **Generation**: greedy decoding; activations via NNsight on NDIF (80 layers, d_model 8192).
- **Labeling**: GPT-4.1-mini judge. "Consolidated" dataset: 0-3 score per mechanism + dominant mechanism + overall_honest; deceptive if mechanism score 3 or overall_honest false and mechanism is unique max; honest examples matched to deceptive within each temptation list; mixed ties dropped -> used for probes/directions. "Steering-eval" dataset: 0-100 per mechanism + coherence, deceptive if >= 50.
- **Judge validation**: 120 human-labeled items; binary agreement fabrication 85%, omission 82%; kappa 0.73 at baseline/moderate steering, 0.39 at extreme; QWK fabrication 0.74, omission 0.56.
- **Probes**: logistic regression on teacher-forced residual stream; train at **last prompt token** or **response tokens** (mean/aggregate over response); layers 20/25/30/35/40; best = **layer 35** (~44% depth). Seeds 42-44. Binary and 3-way (fabrication/omission/honest).
- **Directions**: difference-of-means (mass-mean, Li et al. ITI) from last-prompt-token or response tokens; normalized; added at **layers 19-32, all tokens**, coefficients up to |1.5| (|1.0| best; >1 degrades). Random-direction controls (6 draws). Fabrication flip analysis with Wilson 95% CIs and Newcombe CIs for differences. Perplexity on WikiText-2 as side-effect metric.

## Datasets
Custom GPT-5-mini-generated instructed and spontaneous scenario datasets (sizes not stated in main text); WikiText-2 for perplexity. All in repo.

## Models
Llama-3.1-70B-Instruct only.

## Metrics
Balanced accuracy, AUROC, per-class accuracy, retention (off-diagonal / diagonal), cosine similarity, judge deception score, flip rate, perplexity.

## Key numbers
- Binary probes (L35, response tokens): instructed->instructed 1.000 / AUROC 1.000; spontaneous->instructed 0.980 / 0.999; spontaneous->spontaneous 0.934 / 0.981; instructed(prompt-token-trained)->spontaneous(response) 0.893 / 0.918; spontaneous->spontaneous at last prompt token **0.530 / 0.604** (near chance; class collapse: deceptive acc 0.78, honest 0.28-0.31).
- By layer (seed 42) instructed(prompt)->spontaneous: L20 0.50, L25 0.50, L30 0.64, L35 0.87, L40 0.85.
- Type-level (per-class acc, fabrication/omission/honest): spont->spont .925/.771/.945; spont->instr 1.0/.92/.94; **instr->spont .164/.393/.995** (fails, everything predicted honest).
- Cosine spontaneous vs instructed directions (response tokens, L35): fabrication 0.519, omission 0.435 (chance 0.011); increases when setting axis projected out. At last prompt token: 0.052 / 0.008.
- Steering (last-prompt-token directions, |c|=1): spontaneous fabrication baseline 6.2 -> 84.8 with +instructed direction; omission 49.7 -> 17.4 (-instr) / 87.8 (+spont). Instructed-deceptive fabrication 91.0 -> 6.9 with -instr direction. Flip rate of spontaneously fabricating scenarios to honest: 96.6% (instructed dir), 86.2% (spontaneous dir) vs 35% random.
- Response-derived directions blow up perplexity (e.g., 1313-11146 at |1.5|) vs prompt-derived ~14-18; baseline 4.81.

## Limitations
Single model; synthetic GPT-generated scenarios of unverified realism; low spontaneous fabrication base rate (6.2) -> small n, wide CIs; noisy LLM-judge labels (treats omission/fabrication as exclusive); distortion type not studied; dataset sizes not reported in main text.

## Relevance to hallucination vs. lie
- **Ground truth is supplied in-context**, so the model always "knows" the answer — design guarantees knowledge, cleanly isolating incentive-driven lies. This is a template for our "lie" condition (and a "provided-fact" baseline), but it never tests hallucinations or honest errors; no false-positive analysis on sincerely wrong answers.
- Fabrication = closest to our "lie"; note omission is the dominant spontaneous behavior (base 49.7 vs fabrication 6.2) — incentivized models more often omit than state falsehoods; our lie-labeling should account for evasive/omissive answers, not just false ones.
- Key methodological lessons: (1) instructed-trained probes transfer imperfectly to spontaneous/incentive-driven deception (0.89 binary; type-level fails) — train/eval on incentive-driven on-policy data where possible; (2) **response tokens** carry the detectable signal; last prompt token carries almost none for spontaneous deception (so "intent before answering" isn't linearly visible there), yet prompt-token directions steer best — detection vs control dissociate; (3) mid-to-late layers (~40-50% depth) best.
- Cites Galeone et al. 2026 (arXiv 2606.24952): direction detecting whether model *knows* a subject differs from the direction causing refusal — relevant knowledge/hallucination analog; suggests knowledge-awareness and deception directions could be compared geometrically (cosine) in our study.
- Actionable: compute cosine between a lie direction (diff-of-means lie vs honest-correct) and a hallucination direction (diff-of-means hallucinated vs honest-correct) and a truth direction; report with chance baseline ~1/sqrt(d).
